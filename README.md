# ✨ Features

### 🔳 QR Code Generator

- Generate high-quality QR Codes
- Custom foreground and background colours
- Logo embedding
- Adjustable logo size
- Error correction selection
- PNG download
- SVG export
- Instant preview

---

### 📦 Batch QR Generator

Generate multiple QR Codes simultaneously from structured input.

Features include:

- Batch generation
- Automatic ZIP creation
- Preview gallery
- Metadata generation
- Fast processing

---

### 🖼 Gallery

Manage previously generated QR codes.

- View generated QR codes
- Clean gallery layout
- Download images
- Automatic loading from output folder

---

### 🎨 Modern User Interface

- Glassmorphism-inspired design
- Video backgrounds
- Responsive layout
- Custom CSS styling
- Modern navigation
- Professional dashboard appearance
